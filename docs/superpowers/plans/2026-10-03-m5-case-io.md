## Public interfaces and output contract

```python
# case_io.py
def import_m4(source_root: Path, summary: str = 'failure-reduction/session_summary.json',
              replay: str = 'failure-reduction/replay_case.json',
              profile: str | None = None) -> dict: ...
def revalidate_case(case: dict, source_root: Path) -> dict: ...

# case_store.py
def register_case(case: dict, source_root: Path, workspace: Path) -> Path: ...
def inspect_case(workspace: Path, case_id: str) -> dict: ...
def list_cases(workspace: Path) -> list[dict]: ...
def export_case(workspace: Path, case_id: str, output: Path) -> Path: ...
def reimport_case(index: Path, source_root: Path, workspace: Path) -> Path: ...
```

Failures use `CaseValidationError` with sanitized messages, not source command,
absolute infrastructure paths or raw logs. No external side effects.

`capabilities`: inspection `{status: available|unavailable, reasons: [str]}`,
replay_recipe `{status: complete|incomplete, missing: [dotted fields]}`,
exercised_replay `{status: unverified, reasons: [str]}`, historical_failure
`{status: confirmed|not-established|conflicting, reasons: [str]}`. This first
adapter cannot create fresh exercised-replay verification. Store positive
claims are recomputed, never trusted.

`evidence`: episodes list with episode_id, stage, role (`nominal`, `parent`,
`reduced`, `other`), aggregate reference `{path,sha256}`, global task/reset
identity, raw outcome, optional video/trace references, and safe instruction;
lineage normalized rectangles and decisions only; media_counts videos/traces;
integrity problems as sanitized relative references. No arbitrary original
command, config, operator log, endpoint or private server payload.
`measurements`: elapsed_seconds, physical_episode_count, valid_episode_count
when validated/reportable, cost null. Mark source-reported measurements as such,
not recomputed billing. Metadata-only exports explicitly omit videos/weights.

  `<summary-parent>/runs/<safe-stage-name>/*_aggregate.json` layout. Ignore remote
  output/config paths. Stage names must be single safe filename components.
  Exactly one matching aggregate per stage; missing is insufficient evidence,
  ambiguity/inconsistency is conflicting. Do not guess among duplicates.
- [ ] Require replay/summary model identity and project revision to agree where
  present. Task/reset/seed from replay are strictly typed; derive environment
  seed only from agreeing selected aggregates. Normalize `libero_object` to
  `libero-object`; benchmark class must be exact DiagnosticLIBEROBenchmark.
  Never infer checkpoint/runtime pins from current repository defaults.
- [ ] Normalize opaque equal-RGB agent-view masks only: opacity1, channels all
  equal integer0..255. Match summary/replay final rectangle and aggregate mask;
  preserve nominal disabled mask. Unsupported masks cannot be silently coerced.
- [ ] Reconcile completed stage/result episode counts and identities with raw
  aggregates, expected masks and raw outcomes. Map success to success; exceptions
  to infrastructure_error; timeouts retain episode_timeout and map to existing

## Task 2 — Immutable registration, integrity and export

- [ ] Write failing tests for registration/idempotence, source mutation,
  optional-media loss, export and reimport using the same synthetic sources.
- [ ] Workspace `<case_id>/case.json` stores normalized public metadata;
  `<case_id>/local-source.json` stores the absolute local source root only, never
  exported or returned in public case data. Default CLI workspace is ignored
  `artifacts/cases`. Require distinct workspace outside selected source root;
  reject symlink case directories and malformed case IDs before path joining.
- [ ] Create new registrations exclusively; identical normalized payload/core
  hashes is idempotent. Different content at same ID is refused, never overwrite.
  Source files remain unchanged. Revalidation checks all referenced hashes.
  Core source loss/change invalidates historical confirmation; changed recipe
  sources/profile invalidates recipe readiness. Missing/changed optional media
  changes availability only. Export refuses changed/conflicting core inputs.
- [ ] A missing source binding yields an honest unavailable/incomplete case,
  not a server-wide exception. list_cases returns deterministic case-ID order
  with sanitized unavailable records for malformed entries rather than silently
  hiding known registrations. Never serve local-source.json contents.
- [ ] Export into a newly created nonexisting output directory only: case.json,
  README.md, and replay_recipe.json iff complete. Recipe includes schema version,
  identity/task/policy/runtime/perturbation/protocol only, no executable command.
  README distinguishes saved/fresh evidence, lists missing fields, media omission
  and claim boundaries. Validate before writing; no partial success is reported.
- [ ] Reimport normalized index with explicit source root: validate ID/version,
