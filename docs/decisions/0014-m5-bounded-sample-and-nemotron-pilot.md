# ADR 0014: Bounded external sample and text-only Nemotron pilot

Status: Accepted October 4, 2026, by Jethro's "go" following the two proposals.

Acquire one official-mirror LIBERO Object task HDF5 file, 744.1 MiB with an
800,000,000-byte ceiling, into ignored local storage; checksum and inspect
demo_0 metadata using isolated h5py. This resolves actual format uncertainty
before choosing a restore adapter. Preserve conflicting dataset license
metadata and do not redistribute bytes or claim successful state restoration.

Approve the text-only `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B` candidate on Nebius
Token Factory, at most ten calls and US$0.02 total, for explanations grounded
in deidentified task/outcome/mask metadata and evidence IDs. Exclude media,
private paths/logs and credentials. It cannot decide experiment outcomes or
control robot/cloud execution. Local key setup, account access/balance and
current price checks precede requests; packet/client details require their
bounded implementation plan. Missing access is not permission to change models.

No cloud VM start or simulator adapter is approved by this decision. These
retain M5B's runtime/design and live-budget gates. Expanded M3 stays frozen.
